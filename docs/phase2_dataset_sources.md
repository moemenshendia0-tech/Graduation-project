## Acquisition gate

Before any future acquisition, record the exact artifact URL, publisher, file size, checksum if published, license/terms, archive inventory, and whether any executable is included. Prefer a direct PCAP-only artifact. Do not download mixed archives that contain malware binaries. Respect access controls and publisher terms. No local file should be attributed to a publisher based only on timestamps, labels, or matching network indicators; use `source_verification: unverified` unless cryptographic/source evidence supports a stronger value.
